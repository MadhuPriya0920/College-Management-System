## Project Description

The College Management System is a frontend web application that simulates a college portal with separate interfaces for Students, Faculty, and Administrators.

This project demonstrates frontend development using React, component-based architecture, routing, responsive UI design, and GitHub collaboration.

> **Note:** This project is developed only for frontend demonstration purposes. It does not use any backend or database. User information is temporarily stored using browser localStorage.

## Installation

Clone the repository

```bash
git clone https://github.com/MadhuPriya0920/College-Management-System.git
```

Go to the project folder

```bash
cd College-Management-System
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
